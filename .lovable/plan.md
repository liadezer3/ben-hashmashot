# בוט שעונה אוטומטית לפי תוכן האתר

הפיכת הבוט הקיים (טלגרם + וואטסאפ) מ"בוט שולח התראות" ל**בוט דו-כיווני** שמקבל שאלות מהמשתמשים ועונה עליהן אוטומטית עם AI, על בסיס אותם נתונים בדיוק שמוצגים באתר.

## מה הבוט יידע לענות

1. **זמני שבת וזמני הלכה** — כניסת/יציאת שבת לפי העיר של השואל, חצות, סוף זמן קריאת שמע, שקיעה, פלג המנחה (חישוב חי, אותה לוגיקה כמו באתר).
2. **פרשת השבוע ותוכן תורני** — הפרשה הנוכחית, חגים קרובים, ספירת העומר, תוכן מ-Sefaria.
3. **מידע כללי על האתר** — מה האפליקציה עושה, אילו פיצ'רים יש, קישורים לדפים, מדיניות פרטיות, פרטי יצירת קשר.
4. **נתונים אישיים** — רשימות קניות, אורחים ו-RSVP, משימות שבת, קבוצת המשפחה, העדפות ההתראות — **רק** למשתמש שחיבר את החשבון שלו לבוט.
5. **היסטוריית הצ'אט** — הבוט זוכר את השיחה וממשיך ממנה (לא מתחיל מאפס בכל הודעה).

## איך זה יעבוד (זרימה)

```text
משתמש שולח הודעה בטלגרם/וואטסאפ
        ↓
Webhook  →  Edge Function  bot-webhook
        ↓
זיהוי המשתמש (chat_id בטלגרם / מספר טלפון בוואטסאפ)
        ↓
טעינת היסטוריית שיחה + כלים (tools) של האתר
        ↓
AI עם כלים: זמני שבת, פרשה, פיצ'רים, נתונים אישיים
        ↓
שמירת התשובה בהיסטוריה  →  שליחת התשובה חזרה לאותו ערוץ
```

**סינכרון עם האתר:** הבוט לא מקבל "העתק" של תוכן האתר. הוא קורא את אותם המקורות בזמן אמת (Supabase + חישוב hebcal + Sefaria), כך שכל שינוי באתר או בנתונים משתקף מיד בתשובות, בלי תחזוקה.

## חיבור חשבון (כדי לענות על נתונים אישיים)

- בהגדרות ההתראות באתר יופיע **קוד חיבור חד-פעמי**.
- המשתמש שולח לבוט `/connect <קוד>` — הבוט מקשר את ה-`chat_id` (טלגרם) או מספר הטלפון (וואטסאפ) לחשבון שלו.
- לפני חיבור: הבוט עונה רק על מידע ציבורי (זמנים, פרשה, מידע על האתר) ומזמין לחיבור.

## הערה חשובה על וואטסאפ (0545283419)

טלגרם יעבוד מיד — הטוקן כבר קיים בפרויקט.

לוואטסאפ, Meta מרשה לבוט לענות בחופשיות רק בתוך **חלון 24 שעות** מהודעה שהמשתמש שלח — זה בדיוק המקרה שלנו, אז זה מתאים. אבל נדרש שהמספר 0545283419 יהיה רשום ב-WhatsApp Business Cloud API ושה-webhook יאומת אצל Meta. אבנה את הקוד לשני הערוצים; החלק של האימות אצל Meta הוא שלב שתצטרך להשלים בממשק של Meta (אנחה אותך).

## פרטים טכניים

**מיגרציה** — טבלאות חדשות:
- `bot_conversations` — היסטוריית שיחה (`channel`, `external_id`, `user_id`, `role`, `content`, `created_at`), RLS: המשתמש רואה רק את שלו, edge function דרך service role.
- `bot_links` — קישור ערוץ↔משתמש (`channel`, `external_id` unique, `user_id`, `linked_at`).
- `bot_link_codes` — קודי חיבור חד-פעמיים עם תפוגה.
- GRANTs מלאים לכל טבלה חדשה + פונקציית `SECURITY DEFINER` ליצירת/פדיון קוד.

**Edge Function חדשה `bot-webhook`** (`verify_jwt = false`, אימות `secret_token` בטלגרם ו-`hub.verify_token`/חתימת HMAC בוואטסאפ):
- מנתב טלגרם ווואטסאפ לאותה לוגיקת מוח.
- קורא ל-AI Gateway עם tool calling. כלים: `get_shabbat_times(city)`, `get_daily_halachic_times(city)`, `get_parsha_and_holidays()`, `get_sefaria_daily()`, `get_app_info(topic)`, `get_my_data(kind)`, `get_my_notification_settings()`.
- מודל: `google/gemini-3.6-flash` (מהיר וזול, מתאים לצ'אט תמידי), עם היסטוריה מלאה בכל קריאה.
- טיפול ב-429/402 עם הודעה ברורה בעברית למשתמש.

**קוד משותף** ב-`supabase/functions/_shared/bot/` — זמנים, פרשה, מידע האתר וכלי הנתונים האישיים, כדי שגם `voice-assistant` ו-`friday-concierge` יוכלו להשתמש באותם כלים בהמשך.

**רישום ה-webhook** — הרצת `setWebhook` בטלגרם מהסנדבוקס אחרי הפריסה, ואימות שהוא פעיל.

**UI** — כרטיס "חיבור לבוט" ב-`NotificationSettings`: הצגת קוד חיבור, הוראות בעברית לטלגרם ולוואטסאפ, וסטטוס "מחובר/לא מחובר".
