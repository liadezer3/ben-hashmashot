# מעבר לשליחת מיילים דרך Lovable Emails

## המצב הנוכחי
האפליקציה שולחת מיילים דרך Resend עם כתובת השולח `onboarding@resend.dev`. זו כתובת "ארגז חול" של Resend — היא יכולה לשלוח **רק לכתובת המייל שלך** (הבעלים של החשבון), ולא ללקוחות/בני משפחה אמיתיים. בנוסף אין דומיין מאומת, ולכן מיילים לנמענים אחרים נכשלים או נחסמים.

שלוש פונקציות מעורבות:
- `send-notifications` — מייל בדיקה
- `send-family-notifications` — שליחת זמני שבת לבני משפחה (ידני + אוטומטי)
- `scheduled-push` — תזכורות מתוזמנות

## המטרה
לעבור ל-Lovable Emails: שליחה מדומיין מאומת משלך (למשל `notify.yourdomain.com`), כך שמיילים יגיעו לכל נמען, עם מיתוג "בין השמשות", ללא ניהול ידני של מפתח Resend.

## שלבים

### 1. הגדרת דומיין מייל (פעולה שלך)
תצטרך לחבר דומיין לשליחת מיילים. אפתח עבורך את חלון ההגדרה:
- בחירת דומיין קיים או הוספת חדש
- Lovable יוסיף רשומות DNS (SPF/DKIM) ויאמת אותן אוטומטית

> הדומיין הקיים בחשבון (`wisdom-quotes.com`) במצב כשל אימות — נצטרך דומיין חדש או לתקן אותו.

### 2. הקמת תשתית Lovable Emails
לאחר הגדרת הדומיין, אקים את פונקציית המיילים הטרנזקציונית של Lovable. זה יוצר את התשתית לשליחה מהדומיין המאומת.

### 3. עדכון הפונקציות הקיימות
אעדכן את `sendEmail` בשלוש הפונקציות כך שכתובת השולח (`from`) תהיה הדומיין המאומת שלך (במקום `onboarding@resend.dev`), תוך שמירה על כל עיצוב המייל בעברית, הלוגו והכפתורים הקיימים.

### 4. בדיקה
- שליחת מייל בדיקה לכתובת שאינה שלך כדי לוודא שמגיע
- בדיקת המייל המשפחתי (זמני שבת) מקצה לקצה

## וואטסאפ — הבהרה
Lovable Emails שולח **מיילים בלבד**. הודעות וואטסאפ ימשיכו לעבוד כפי שהן היום (קישורי `wa.me` בחינם בצד הלקוח, או Meta WhatsApp Cloud API אם תרצה אוטומציה מלאה בהמשך). המעבר הזה לא משנה את הוואטסאפ.

## פרטים טכניים
- כל קריאות `sendEmail` הקיימות נשארות במבנה דומה; רק כתובת ה-`from` והמפתח מנוהלים דרך תשתית Lovable Emails והדומיין המאומת.
- תמחור: עד 50,000 מיילים/חודש כלולים בתוכניות בתשלום; מעבר לכך $1 ל-1,000. מוגבל ל-100 מיילים/שעה לכל workspace.
- אין שינוי בלוגיקת התזמון, ההעדפות לפי ערוץ, או ה-DB.

לאחר אישור — נתחיל בהגדרת הדומיין.
